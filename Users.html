Notable projects and organizations using Meson#

If you’re aware of a notable project that uses Meson, please file a pull-request for it. For other projects using Meson, you may be interested in this GitHub search. Some additional projects are listed in the meson GitHub topic.

Xorg#

  • Xserver, the X.org display server

Gnome#

  • GTK, the multi-platform toolkit used by GNOME

  • GLib, cross-platform C library used by GTK+ and GStreamer

Enlightenment#

  • EFL, multiplatform set of libraries, used by the Enlightenment windows manager and other projects

Elementary OS#

cinnamon-desktop#

  • Nemo, the file manager for the Cinnamon desktop environment

Budgie Desktop#

Other Notable projects#

  • FreeType, widely used open source font rendering engine

  • GIMP, an image manipulation program (master branch)

  • GStreamer, multimedia framework

  • Git, “the information manager from hell”

  • HarfBuzz, a text shaping engine

  • HexChat, a cross-platform IRC client in C

  • LXC, Linux container runtime

  • Linux PAM, The Pluggable Authentication Modules project for Linux

  • Mesa, an open source graphics driver project

  • mpv, a free, open source, and cross-platform media player

  • NumPy, a Python package for scientific computing

  • OpenH264, open source H.264 codec

  • OpenRC, an init system for Unix-like operating systems

  • Pacman, a package manager for Arch Linux

  • PicoLibc, a standard C library for small embedded systems with limited RAM

  • PipeWire, a framework for video and audio for containerized applications

  • PostgreSQL, an advanced open source relational database

  • QEMU, a processor emulator and virtualizer

  • SciPy, an open-source software for mathematics, science, and engineering

  • systemd, the init system

  • Wayland, common display protocol
