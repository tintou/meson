## assert()

Abort with an error message if `condition` evaluates to `false`.

<pre><code class="language-meson"># Abort with an error message if `condition` evaluates to `false`
[[#@void]] assert(
  [[#@bool]]                                  <a href="#assert_condition"><b>condition</b></a>,     # Abort if this evaluates to `false`
  [[#@str]]                                   [<a href="#assert_message"><b>message</b></a>],     # The error message to print
)</code></pre>


```{note}
The `message` argument is optional since 0.53.0 and defaults to print the condition statement.
```
