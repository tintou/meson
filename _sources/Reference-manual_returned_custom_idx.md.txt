# Custom target index (`custom_idx`)

References a specific output file of a [[@custom_tgt]] object.


## Returned by

Custom target index objects are returned by the following functions and methods:
- [[custom_tgt.[index]]]




## Custom target index methods

<p style="padding: 7.5px; margin: 0px;"></p>

### custom_idx.full_path()

Returns a full path pointing to the result target file
NOTE: In most cases using the object itself will do the same job as
this and will also allow Meson to setup inter-target dependencies
correctly. Please file a bug if that doesn't work for you.

See [[custom_tgt.full_path]]
