## import()

Imports the given extension module. Returns an object that can be used to call
the methods of the module. Here's an example for a hypothetical `testmod`
module.

[[#@module]] import(

  # Keyword arguments:

  ### Example

```meson
tmod = import('testmod')
tmod.do_something()
```
